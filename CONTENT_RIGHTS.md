# Content Rights and Provenance Policy

Project Ambient does not operate an upload-driven wallpaper marketplace. The default workflow indexes media the user already controls.

Every distributable channel pack must record:

- Creator and rightsholder.
- Canonical source URL.
- License name and URL.
- Whether redistribution and commercial use are allowed.
- Required attribution and share-alike terms.
- Asset checksum and acquisition date.
- AI-generated, human-made, mixed, or unknown provenance.
- Any trademark, privacy, publicity, or geographic restrictions.

No pack may include executable payloads or fetch arbitrary code. Remote media providers must be reviewed against their current API and content terms. Project Ambient will not ship a Pexels API connector under terms that prohibit wallpaper applications.

For sports, use personal media, public-domain material, or media supplied under an explicit rightsholder agreement. Schedules and scores do not grant a license to footage, photographs, broadcasts, logos, or athlete likenesses.

Submit a private security report titled “Rights report” for sensitive takedown requests; include the asset identifier, rights basis, and contact information. Maintainers may remove disputed material while a report is reviewed.
