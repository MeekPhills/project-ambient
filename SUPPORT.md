# Support

Use GitHub Discussions for setup questions, feature ideas, channel recipes, and “show your setup” posts. Use Issues for reproducible bugs.

For a useful bug report, include:

- Project Ambient version and macOS version.
- Mac model and chip family.
- Number and orientation of displays.
- Whether Aerial is installed.
- What happened around sleep, wake, unlock, docking, or a Space change.
- The diagnostic export, after reviewing it for information you do not want to share.

Never attach personal media, full filesystem paths, secrets, or calendar content. Security issues belong in private vulnerability reporting as described in [SECURITY.md](SECURITY.md).
