# Accessibility

Project Ambient treats accessibility as a release requirement.

The Mac app and public site aim to support complete keyboard operation, meaningful VoiceOver labels, system text sizing, high-contrast states, Reduce Motion, and a still-image alternative to motion. Important state is never communicated through animation alone.

The project’s accessibility acceptance checks include:

- Complete onboarding and channel activation without a pointing device.
- Hear the current channel, next item, selection reason, and power state with VoiceOver.
- Stop or avoid decorative motion through the system Reduce Motion setting.
- Maintain visible keyboard focus and sufficient color contrast.
- Avoid automatic audio and flashing content.
- Keep recovery and restore controls reachable without navigating a media gallery.

Accessibility defects are bugs. Please report the exact control and assistive-technology setup through GitHub Issues without including private media.
