# Roadmap

The roadmap is ordered by user trust, not feature count.

## 0.1 alpha — ship now

- Local folder import and catalog.
- Explainable channels with Now / Next / Why.
- Public-API still wallpaper application and exact restore.
- Power policy, pause, resume, next, and history.
- Aerial-compatible video export.
- Native UI, CLI, local MCP, hosted MCP review mode, public site, and release automation.

## 0.2 — reliability

- Display-identity reconciliation across docking and hot-plugging.
- Last-known-good still fallback and one-click repair.
- Progressive indexing, duplicate detection, aspect/resolution facets.
- App Intents and Shortcuts parity.
- Published energy baselines across Apple silicon generations.
- Signed, notarized automatic updates after publisher credentials are configured.

## 0.3 — context

- Deterministic time, sunrise/sunset, Focus, power, display, and calendar-state triggers.
- Priority, conflict explanation, test mode, and reversible rule history.
- Portable `.ambient` recipe manifests that do not redistribute media.
- Creator attribution and rights metadata views.

## 0.4 — remote control

- End-to-end authenticated outbound device bridge.
- Per-device keys, revocation, audit history, expiration, and deletion.
- Stable production HTTPS MCP with SLOs and directory submissions.

## Later, only with clear demand

- Encrypted multi-device sync, managed fleets, venue mode, paid creator packs, additional desktop platforms, and a curated rights-aware provider catalog.

## Non-goals

- Private macOS wallpaper database modification.
- An unrestricted upload marketplace.
- Scraping sports broadcasts or distributing unlicensed highlights.
- A general remote shell or arbitrary filesystem interface.
- Generative wallpaper spam as the product’s discovery model.
